# 跨摄像头 ReID 走测与阈值校准

## 采集要求

1. 至少 5 人参与，每个人使用固定编号，例如 `P01` 到 `P05`。
2. 每个人依次经过两个摄像头，每个方向至少 2 次，人与人之间间隔 20 秒以上。
3. 至少包含一次正面、一次背面、一次手持物或背包变化；不要在一次走测中换整套衣服。
4. 在观察表记录每次经过产生的 crop ID、摄像头和时间。
5. 为每个正样本配 2 个相近时间的不同人负样本，避免只用外观差异特别大的简单负例。

## 标注文件

优先从观察表点「找相似」进入 ReID 页面，放大图片核对后，在每个候选上点「同一个人」或
「不是同一个人」。同一查询图和候选图再次点击会更新原记录，不会重复追加；这些反馈只进入
`reid_match_feedback` 校准表，**不会直接修改当前排序、阈值或 `person_id`**。

页面右侧「导出全部标注」会下载 `reid-feedback.csv`，格式可直接传给评估脚本。
服务器导出接口是 `/api/reid/feedback/export.csv`，启用认证时须使用已有凭据；不要把密码放进
URL、命令历史或公开报告。CSV 包含人员抓拍标识，只存放在受控私密目录，不提交 Git。

CSV 保留点击当时的人体分数、人脸相似度与可靠性、标签计数、融合分数和判定说明。
评估脚本是纯离线诊断：只读取 CSV，不导入应用配置，不访问数据库、媒体、网络或模型，
不重算向量，也不修改阈值、缓存或身份绑定。更换模型后的效果必须重新检索、人工核对并
导出新的分数，不能把旧证据快照当成新模型的评测结果。

如果需要先离线组织现场编号和备注，也可以复制 `docs/reid-walkthrough-template.csv`。每行是一对抓拍：

- `query_crop_id`：查询抓拍。
- `candidate_crop_id`：候选抓拍。
- `same_person`：同一个人填 `true`，不同人填 `false`。
- `person_code`：现场编号，仅用于审计，不进入系统身份库。
- `notes`：正面、背面、遮挡、背包等情况。

模板只组织人工真值，没有推理分数；直接评估时相应模态的覆盖率为 0，不会把缺失分数或
未知标签补成负例。`same_person` 必须明确填 true/false，空白、unknown 和矛盾标注会被拒绝。

至少准备有有效分数的 30 个正样本对和 60 个负样本对，才会生成该模态的训练阈值建议。
这只是样本下限，不意味着已经完成独立、跨人员的现场准确率验证。

## 运行评估

```bash
cd /opt/sightindex
.venv/bin/python scripts/evaluate_reid_walkthrough.py \
  data/reports/reid-feedback.csv \
  --body-threshold 0.50 --face-threshold 0.45 \
  --face-min-reliability 0.70 --attribute-hard-conflicts 2 \
  --output data/reports/reid-calibration-report.json
```

上面是示例参数，不是自动读取的生产参数。必须核对实际配置后显式传入；默认值也会在报告中记录。
输出文件必须尚不存在，父目录须已创建；报告以 `0600` 权限新建，不覆盖旧报告、不接受符号链接。
先以 `umask 077` 在所选部署根创建 `data/reports` 私密目录，每次使用新的输出文件名；
旧实例使用 `/home/SightIndex`，不要按示例误切到另一份 `/opt` checkout。

报告分别给出：

- 人体、人脸和标签各自的证据覆盖率、弃权数，以及固定阈值下的混淆矩阵和成对指标。
- 人脸仅对达到指定可靠性、且有相似度的样本作判断；无可靠人脸保持中性。
- 标签按指定的累计稳定冲突数诊断；没有可比较标签时弃权，不视为一致或冲突。
- 训练集阈值建议；样本不足时阈值为 null，状态为 `insufficient_scored_samples`。

可用 `--group-column person_code --holdout-group P05` 显式划分训练与留出组，留出组不会参与
拟合阈值，跨两组共享抓拍 ID 会被拒绝。现场编号是否真正按人员独立仍需人工确认；报告不会
自动声称完成身份独立测试。未指定留出集时只是同一批标注的离线诊断，不是泛化准确率。

报告不包含抓拍 ID、分组编号或自由文本；成对精确率/召回率不是检索 Rank-1 或 mAP。
阈值变更必须经过人工批准，保留私密 CSV、汇总报告及参数，并在变更后重跑页面回归。
